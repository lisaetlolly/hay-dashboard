# 618 加购面板修复 - 交接包

## 这是啥

DB 上现有的「618 预热蓄水期加购面板」按类目（配饰/家具/灯具）拆分的商品加购人数算错了。
这个包里是修复需要的所有东西，让电脑上的 Claude Code 自动改 + push。

## 怎么用

### 1. 把这整个 `handoff/` 文件夹放进你仓库根目录

```bash
# 假设你下载解压后得到 handoff/ 文件夹
cp -r handoff/ /path/to/your/repo/
cd /path/to/your/repo/
```

### 2. 启动 Claude Code，复制 PROMPT.md 里的提示词粘贴进去

```bash
cd /path/to/your/repo/
claude
# 在 Claude Code 里粘贴 handoff/PROMPT.md 中三个反引号之间的内容
```

### 3. Claude Code 会按提示词的步骤执行

- 读 spec 文件理解上下文
- grep 仓库找当前面板的 SQL/代码
- 按 spec 改写
- 用测试用例（17 天 × 4 项 = 68 个对照点）验证
- 验证通过 → commit + push
- 验证不通过 → 报告差异等你确认

### 4. 改完之后

- 不要急着删 `handoff/`，留着以后再调时还有上下文
- 或者把它移到 `docs/` 之类的地方

## 文件结构

```
handoff/
├── README.md                  ← 你正在看的这个
├── PROMPT.md                  ← 给 Claude Code 的提示词，复制这个里面的
├── spec/
│   ├── 分类逻辑规范.md         ← 正确逻辑 + SQL 伪代码 + 5 个常见踩坑（必读）
│   ├── 测试用例.csv            ← 17 天 × 4 项已验证数据，改完跑这个对照
│   ├── 思维逻辑.md             ← Claude 推理过程（看 4-6 节就够）
│   └── 对话记录.md             ← 我和 Claude 排查问题的过程，了解为什么这么改
└── data/
    ├── 分类映射表.xlsx          ← 原始映射表（790 行）
    ├── 25年5月_合并.xlsx        ← 已合并的 2025 五月 12 天日报
    ├── 2026-05_合并.xlsx        ← 已合并的 2026 五月 5 天日报
    ├── 同比参考表.xlsx          ← 用户给的 ground truth（618预热蓄水期加购趋势底表0506.xlsx）
    └── 同比最终结果.xlsx        ← Claude 算出来的最终对照版
```

## 三个最关键的事（如果你只看一段）

1. **映射表里的「配件」和「配饰」是同一类**（数据质量问题），合并为「配饰」
2. **商品在映射表里就用映射表的分类**——别因为名字带"已合并"或者是"-"就排除（5 个商品因此被错杀，每天少算约 1-5 个加购）
3. **`商品名 LIKE '%椅%'` 而不是 `'%椅子%'`**——餐椅、扶手椅、吧椅都要包含

详见 `spec/分类逻辑规范.md` 第 4 节。
