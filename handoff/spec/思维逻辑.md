# 思维逻辑（精简版）

> 我帮她整理这件事时的核心推理过程。看 4-6 节就够了，前几节是怎么发现现有面板算错的。

## 1. 起点：把 12+5 个日报合并

用户先后给了三个 zip：
- `25年5月.zip`：12 个文件，2025-05-01 到 2025-05-12 每天一个
- `2026-05.zip`：5 个文件，2026-05-01 到 2026-05-05（其中 5/3 那个文件不完整，只有 29 行，对方后来补了完整版）
- `2026-05_2.zip`：上面 5/3 的修正版

每个 .xls 文件都是生意参谋导出的固定结构：38 列，表头在第 5 行（0-indexed=4）。
直接 pandas + xlrd 读，把多文件 concat 起来，按 统计日期 排序。

## 2. 分类映射表的数据质量问题

用户给了一份 `分类映射表.xlsx`：3 列（商品ID、一级、二级），769 行。
**关键发现**：
- 一级有 5 个值：配饰(348)、配件(2)、家具(150)、灯具(66)、购物金(2)
- 但 **201 个商品 ID 同时挂着「配饰」和「配件」两个标签，二级完全一致**
- 这说明配饰/配件就是同一类，只是历史录入时键盘打错或者两个人打的，没规范

→ **必须合并配饰 + 配件 = 配饰**（用「配饰」是因为参考表用的是这个名字）

后来用户给了一个更新版本的映射表（在 618 参考文件的"分类底表"sheet 里），790 行，494 个独立商品 ID。结构一样，问题一样。

## 3. 用户给的分类规则

用户说："带'灯'的标题属于灯具，沙发、椅子、茶几、桌子是家具，狗床和其他属于配件"

这是给**没在映射表里的商品**用的规则。问题：
- 用户说"配件"但映射表里主流是"配饰"——按参考表统一用配饰
- "椅子" 这个词太长，"扶手椅"、"餐椅" 不会匹配——用单字"椅"
- 同理用"桌"而非"桌子"
- "狗床和其他" 的"其他"是兜底，等价于"以上规则都不匹配"

## 4. 最关键的踩坑：不能按关键词预排除

我第一版做完，对照参考表发现 2025 每天都比参考少 1-5 个加购人数。差异点都在配饰里。

排查发现是这 5 个商品被我错杀了：

| 商品ID | 商品名称 | 映射表分类 | 我之前的处理 |
|---|---|---|---|
| 740660636320 | HAY购物金 | 购物金 | 排除（√ 这个排除是对的，但要明确归到购物金） |
| 582883515928 | 【已合并】HAY Colour Crate S | 配饰 | 排除（× 不该排除） |
| 873879065008 | - | 家具 | 排除（× 不该排除） |
| 761701702608 | - | 配饰 | 排除（× 不该排除，每天有 1-4 个加购） |
| 649293306984 | - | 配饰 | 排除（× 不该排除） |

**结论：商品 ID 在映射表里就用映射表的分类，不要因为名字长得"像被排除的"就排除。**
名字关键词排除只对"没在映射表里"的商品才生效。

排查方法是：把我的输出和参考表逐行 diff，看哪些 (日期, 商品ID) 在 ref 里但不在我这；哪些反过来；哪些都在但分类/数值不同。最后剩余差异都能定位到具体某几个商品。

## 5. 验证策略

参考表给了 2025 前 7 天 + 2026 全 5 天的逐类目预期值，共 12 天 × 4 项（配饰/家具/灯具/总计）= 48 个数据点。改完逻辑后逐个核对，全部 ✓。

剩余的 2025 后 5 天（5/8-5/12）参考表里没有预期值，只能靠"逻辑一致性"信任——同一逻辑跑前 7 天对得上，跑后 5 天应该也对。

## 6. 数据格式注意事项

`商品加购人数` 这列在两年的源文件里类型可能不一样：
- 2025 的 .xls：纯数字 int
- 2026 的 .xls：可能是带逗号的字符串（"1,234"）

我的 Python 代码里写了一个 `parse_num()`：
```python
def parse_num(v):
    if pd.isna(v): return 0.0
    s = str(v).strip().replace(',','').replace('%','')
    if s in ('-', '', 'nan'): return 0.0
    return float(s)
```

如果你们的 ETL 是 SQL 直接读的，CAST 之前要 REPLACE 掉逗号和 "-"。

## 7. 最终验证

跑完一遍，2025 五月 12 天 + 2026 五月 5 天的所有 (日期 × 类目) = 51 个数据点，对照参考表的 48 个全过。
另外的 3 个空缺点（2025-05-08 总计 1166 在参考表里有，配饰/家具/灯具 缺）我的逻辑产出的是 957/132/77，三者加和 = 1166，自洽。

参考数字详见 `测试用例.csv`，改完面板用这 17 行数据 × 4 项 = 68 个对照点全跑一遍即可。
